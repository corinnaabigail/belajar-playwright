- tests/
Contains all Playwright test files. By default, Playwright looks for test cases inside this folder when running tests.

- playwright.config
The main configuration file used to define browser settings, timeouts, parallel execution, reports, and other global test options.

- node_modules/
Stores all project dependencies installed via npm, including Playwright and browser binaries. This folder is auto-generated and should not be edited manually.

- package.json
Manages project metadata, dependencies, and npm scripts used to run Playwright tests.
